### 9.2 Deploy proces (Netlify + Domenca)

**Hosting odločitev:** Netlify za Next.js aplikacijo, Domenca samo za domeno (DNS).

**Koraki:**
1. Push kode v GitHub (ali drag-and-drop deploy na Netlify)
2. Netlify → New site from Git → izberi repozitorij
3. Build command: `npm run build` (avtomatsko)
4. Publish directory: `.next` (avtomatsko)
5. Deploy na `<ime>.netlify.app` poddomeni → testiraj
6. Site settings → Domain management → Add custom domain → `lasnisistem.com`

**DNS za Domenca — IZBRANA VARIANTA: Obdržimo Domenca DNS (ker MX/e-mail ostane pri Domenci)**

Samo spletna stran kaže na Netlify, vsi ostali zapisi (MX, SPF, DKIM, DMARC) ostanejo nespremenjeni.

**E-mail šablona za Domenco (pošlji ŠELE PO Netlify deploy-u, ker potrebuješ točno Netlify poddomeno):**

```
Pozdravljeni,

spletna stran lasnisistem.com gostuje na Netlify. Prosim, posodobite DNS zapise
za to domeno kot sledi:

A zapis (apex domena):
- Host: lasnisistem.com (oz. @)
- Type: A
- Value: 75.2.60.5
- TTL: 3600

CNAME zapis (www poddomena):
- Host: www
- Type: CNAME
- Value: <NETLIFY_SITE_NAME>.netlify.app
- TTL: 3600

Vse ostale zapise (MX, SPF, DKIM, DMARC) prosim OHRANITE NESPREMENJENE —
email ostaja pri Domenci.

Hvala.
```

**Vrednosti:**
- `75.2.60.5` je standardni Netlify load balancer IP (fiksno)
- `<NETLIFY_SITE_NAME>` dobiš v Netlify UI po deploy-u (npr. `lasni-sistem.netlify.app`). Netlify tudi sam pokaže točne zapise v Site settings → Domain management → Add custom domain.

**Alternativa (če Domenca podpira ALIAS/ANAME):** namesto A zapisa za apex, uporabi ALIAS `lasnisistem.com` → `apex-loadbalancer.netlify.com`. Večina slovenskih registrarjev tega ne podpira, zato je A zapis varnejša izbira.
